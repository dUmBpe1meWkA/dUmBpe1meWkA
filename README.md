## Командный проект с языковыми моделями

**ЛингвоКот / АКМ-Вест · БЯМ-пайплайн для автоматизации перевода**

В составе команды подготовил проектное решение для интеграции больших языковых моделей в переводческий процесс: анализ документа, пакетный перевод, проверки качества и проверка человеком.

Совместно с командой описал преобразование двуязычных DOCX/MXLIFF в JSON, сохранение тегов и защищённых элементов, промпты и контракты ответов моделей. В рамках командного разбора кейса на **1 513 сегментов** выявлены **655 проблемных переводов**; описаны правила их исправления без нарушения структуры документа.

**Инструменты:** Python · DOCX / WordprocessingML · JSON Schema · LLM prompting · XLIFF / MXLIFF
